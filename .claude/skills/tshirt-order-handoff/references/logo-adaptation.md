# 細密ロゴを、小さな左胸用（約10cm幅・1色・黒生地）に直す（実績からの一般化）
- 対象: 斜線ハッチ・細いセリフ・濃淡の絵・細い線画マークを含むロゴ。会社のシルク基準(線1mm/隙間2mm)で測ると、**インクの約3割が線として消え、約2割強が隙間で埋まった**（一例）。
- 有効だった手順: 高解像度ラスタ→(1)濃淡の絵は2値のベタ図形に置換 (2)斜線文字は「外形リング＋太い斜線」に再構成 (3)細線は0.3〜0.6mm太らせ→クローズ/オープンで隙間・突起を整理 (4) potracer でベクター化。社内の暫定基準(線0.5mm/隙間0.7mm)は通ったが、**会社基準(1/2mm)には届かない**。
- 無効だった手順: 基準(1/2mm)に合わせて全体を太らせる → 文字が塊になり、小さなマークや点の輪が崩壊。配置上限までの拡大(+約1割)では救えない。
- 教訓: 基準が1/2mmの会社では、細密ロゴは**方式変更(DTF)か、別デザイン**が現実解。依頼者が「再現性なしでよい」と判断したら、現状データ＋明記で入稿。
- 小さく直すコツ: 文字は太い書体で再描画し外形＋斜線／輪やマークは円＋太い線に単純化。
