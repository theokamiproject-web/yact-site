# 細密ロゴを小さな左胸用に直す（実績）
- 元ロゴ（斜線ハッチ・細セリフ・鉛筆画の玉・細い線画マーク）を 約90mm幅・1色・黒地へ。会社のシルク基準(1mm/2mm)では**インクの約27%が線として消え、24%が隙間で埋まる**。
- 有効だった手順: 高解像度ラスタ→(1)玉の濃淡は2値のベタ図形に置換 (2)斜線文字は「外形リング＋太い斜線」に再構成 (3)細線は0.3〜0.6mm太らせ→クローズ/オープンで隙間・突起を整理 (4) potracer でベクター化。tee-check(暫定0.5/0.7mm)は通ったが、**会社基準(1/2mm)には届かない**。
- 無効だった手順: 基準(1/2mm)に合わせて全体を太らせる → 文字が塊になり、結び目・マーク・点の輪が崩壊。拡大(+9%)では救えない。
- 教訓: 基準が1/2mmの会社では、ハッチ等の細密ロゴは**方式変更(DTF)か、別デザイン**が現実解。ユーザーが「再現性なしでよい」と判断したら、現状データ＋明記で入稿。
- 小さな楕円/文字置換のコツ: 文字は太い書体で再描画し外形＋斜線にする／輪やマークは単純化(円＋太い線)／1つの花形（輪5つ）で結び目を代替。
