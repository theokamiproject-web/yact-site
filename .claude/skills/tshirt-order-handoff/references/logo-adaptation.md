# 細密ロゴを小型の版に直すときの要点（一般則）
- 細い線・ハッチ・細セリフ・濃淡のある絵柄は、会社の最小線幅/隙間に届かず、**インクの一部が線として消え、別の一部が隙間として埋まる**。`feature_check.py` で割合を測ってから手を入れる。
- 有効だった手順: 高解像度ラスタから (1)濃淡は2値のベタ図形に置換 (2)細い文字は太い書体で再描画し外形＋太い斜線に再構成 (3)細線を少しだけ太らせ、クローズ/オープンで隙間・突起を整理 (4) potracer でベクター化。
- 無効だった手順: 基準に合わせて全体を一律に太らせる → 文字が塊になり、細部が崩壊。小さな拡大(約1割)では基準に届かないことが多い（必ず拡大率で再計算する）。
- **補正は1回まで**。1回で崩れたら自動補正を続けず、方式変更(DTF等)／簡略化の作り直し／会社のデータチェック／ユーザーが了承した場合のみ現状入稿、のどれかに判断を戻す。
- ラスター混在の版は、細線チェッカーのPASSを信用しない。完成画像を会社値で実測する。
