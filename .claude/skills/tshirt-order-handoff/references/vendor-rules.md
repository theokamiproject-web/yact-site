# 印刷会社ルールの観測例（※特定時点に確認した観測例であり、実際の入稿前には必ず印刷会社の最新仕様を再確認する）
このファイルの数値・条件は**恒久ルールではない**。Skill本体・スクリプトには固定していない。会社仕様と社内目安が異なる場合は**会社仕様を優先**する。
## 観測例A（シルクスクリーン主体の小ロット業者・2026年秋に確認）
- 入稿: 注文後の自動返信メールに添付して返信。形式は ai/PDF/画像系。文字はアウトライン化、画像は埋め込み。SVGの記載はなし。
- シルクの最小線幅・最小隙間の下限が示されていた（例として線 1mm 級・隙間 2mm 級）。下限未満は再現性なし・再入稿依頼の可能性。DTFは細線の下限がより小さいが、極細は不可/剥がれの注意書き。
- 色: 標準インク見本から選ぶ。指定色は別料金。下地(白引き)の説明は黒生地向けには記載なし → 問い合わせ項目に入れる。
- 特急は完成イメージ確認後の日数で段階的な追加料金（税込の定額）。繁忙期は不可の場合あり。入稿締切日は設定なし。
## 一般則（会社を問わず確認する項目）
- 少量は版代の都合で単価が高い。枚数の区切りで単価が下がる会社がある。
- 納期は営業日基準で、注文確定・入稿時刻・校正往復で発送日が動く。
## 使い方
1. 依頼のたびに会社の公式ページを取得し、最小線幅・隙間・形式・下地・特急条件を**その時点の値**で表にする（WebFetch）。
2. その値を `feature_check.py --min-line --min-gap` と `build_handoff.py` に渡す。
3. 価格・納期は案件ごとに問い合わせて確認する（このファイルの例は使わない）。
