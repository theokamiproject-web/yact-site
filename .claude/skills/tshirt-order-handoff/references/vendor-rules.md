# 印刷会社の入稿ルール：観測例（匿名・特定時点）
**位置づけ**: 2026-10 時点で、ある国内オンライン特急プリント業者の公開ページから読み取った例（会社名・連絡先・価格は載せない）。**会社ごとにルールは異なる。実際の入稿前に、必ず相手先の最新の入稿案内を再確認する。**
- 入稿方法: 注文後の自動返信メールへデータを添付して返信する形式、郵送入稿を用意している会社がある。
- 形式: Illustrator(ai。旧バージョン指定あり)・PDF・PNG・JPG 等。SVG は記載がない会社が多い → PDF で渡す。文字はアウトライン化、画像は埋め込み。
- シルクスクリーン: 線 1mm 以上・隙間 2mm 以上が条件（未満は再現性なし・再入稿の可能性）。DTF: 0.5mm 以下の細線は不可/剥がれ。
- 色: インク見本から選ぶ方式／指定色(パントーン等)は別料金、という会社がある。黒生地の下地(白)の扱いが明記されない会社もある → 問い合わせる。
- 特急: 発送までの営業日数で料金が変わる。繁忙期は受けられない場合がある。入稿締切日を設けない会社もある。
## 一般則
- 20枚前後はシルクの下限付近。ある枚数以上で単価が下がる会社が多い。
- 納期は営業日基準。注文確定・入稿の時刻で発送日が動く。
