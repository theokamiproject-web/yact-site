# 印刷所メモ（特定時点に確認した観測例であり、実際の入稿前には印刷会社の最新仕様を再確認する。会社仕様がSkillの目安と違えば会社仕様を優先）
## プリントパック（小ロット無線綴じ）
- 判型 A4/A5/B5/B6。ページ数は**表紙4P込み**(24〜340P、2P刻み)。50部可。納期1〜10営業日から選択。
- 入稿: ファイル数=注文ページ数、単ページ可、ページ番号でファイル名、フォルダごと圧縮。白ページは白データが必要。背幅は総ページ数から自動(ユーザーは考慮不要と指示)。
- 塗り足し3mm: B5=182×257 → 入稿PDFは188×263。
## ちょ古っ都製本工房（参考）
- 本文PDFと表紙PDF(表1-4)を別アップロードする形式。表紙は断ち切り「しない」/ありの設定に注意。注文後の差し替えは、製造開始前なら再アップロードか連絡で対応可能な場合がある(要確認)。
## 共通
- モノクロはGray変換(K100のみ)。ink coverageで C/M/Y=0 を確認。
- 金額はページ数・部数で変わる。見積り時はソース(公式の料金表)を提示し、リスク/メリットを併記。
