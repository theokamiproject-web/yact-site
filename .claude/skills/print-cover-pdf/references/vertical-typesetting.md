# 縦組みの約物処理（W3C「日本語組版処理の要件」JLReq の要点を、実装向けに自分の言葉で整理）
原典: https://w3c.github.io/jlreq/?lang=ja （W3C文書。規則の詳細・例外は原典を読む。ここは要点と実装の対応のみ）

| 文字 | 縦組みでの扱い | `lib.mjs` の実装 |
|---|---|---|
| 、 。 ， ． | 字面の**右上**に寄せる | 実装済み（右へ0.55em・上へ0.62em。書体で微調整が要る場合あり） |
| 長音「ー」・波線「〜」・ダッシュ「―」・リーダー「…」 | 90°回転して縦棒/縦の波にする | 実装済み（セル中心で時計回り90°） |
| 括弧 「」『』（）【】など | 90°回転（開きは上、閉じは下に向く） | 実装済み |
| 小書き仮名 ゃゅょっ ぁぃ… | 右上へ少し寄せる | 実装済み（0.1em。簡易） |
| 数字・欧文 | 1〜2桁の数字は正立（縦中横）、欧文は横倒しか1字ずつ正立 | **未対応**: 題字に数字・欧文を混ぜる場合は、漢数字にするか、`htext` で別に置く |
| 行頭禁則・行末禁則（句読点を行頭に置かない等） | 行の折り返しで守る | **未対応**: `vtext` は1列にそのまま並べる。複数列に折る場合は手で区切る |
| ぶら下げ | 行末の句読点を版面の外へ出してよい | 未対応 |

## 確認方法
`vtext` を使う案は、約物を含む文言を**実画像で見る**（`review_sheet.py` の原寸欄）。回転・位置の誤りは数値では検出しない。
題字に約物を使うこと自体を避けるのが最も安全（装飾として使う場合のみ処理する）。
