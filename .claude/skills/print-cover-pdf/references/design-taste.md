# デザインの進め方と、依頼者の好みの観測例（依頼者ごとに確認。固定の恒久ルールではない）
## 収束を速くする
1. 初回の3案は**抽象度で離す**（文字のみ／図案／図形）。方向が同じ3案は「ダサい」の再提出になる。
2. 却下理由を**次の1案の制約**にする。言葉をそのまま設計に落とす: 「もっとダイナミック」→ 大きさの対比・傾き・斜め構図／「具体的すぎ」→ ものを描かず図形・線だけ／「図形が多い」→ 要素を2〜3種に／「線だけで」→ 塗り・網点・斜線を全廃。
3. 毎回、**前回の失敗要素を消してから足す**。足し算で直すと悪化した（要素過多→却下）。
4. 見た目の確認は必ず実画像を読む（図形の重なり・見切れ・ロゴ衝突は数値より画像で気づく）。
## 観測された傾向の一例
- 「寄せ集め」「ダサい」を嫌う。**少ない大きな要素・強い対比・シンプル**を好む。
- 具体物の写実より、図形・線による**抽象**。ただし主題の気配は構造（配置・比率）で示す。
- 短い返答で方向を示す。説明は簡潔、リスクとメリット、数字（余白mm・黒面積%）を添える。
- 素材が届いていない場合、仮置きして進めてよいが、**毎回の報告で未受領と明記**。
- 好みが不明な依頼者には、先に抽象度の違う3案で当たりを取る。
