# デザインの進め方（収束を速くするための一般則。好みは案件・依頼者ごとに再確認する）
1. 初回の3案は**抽象度で離す**（文字のみ／図案／図形）。方向が同じ3案は再提出になりやすい。
2. 却下理由を**次の1案の制約**にする: 「もっとダイナミック」→ 大きさの対比・傾き・斜め構図／「具体的すぎ」→ 図形・線だけ／「図形が多い」→ 要素を2〜3種に／「線だけで」→ 塗り・網点・斜線を全廃。
3. 前回の失敗要素を**消してから**足す（足し算で直すと悪化しやすい）。
4. 確認は必ず実画像を読む（重なり・見切れ・ロゴ衝突は数値より画像で気づく）。
5. 過去の依頼者では「少ない大きな要素・強い対比」を好む例が多かった。これは一例であり、新しい依頼者には初回で確認する。
6. 素材が届いていない場合は仮置きして進めてよいが、報告のたびに未受領と明記。
