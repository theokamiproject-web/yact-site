# ブリーフ（着手前に1回だけ聞く。デザイン作業はこれが埋まってから）
依頼者の手間は約5分。これで「ダサい」の往復（前例: 6ラウンドで収束せず終了）を初回で減らす。

## 1. 参考画像（必須）
- **好き 3〜5点**＋各一言の理由（「余白が広い」「字が大きい」「線が手描き」など）。ジャンル不問（ポスター・本の装丁・服・建築写真でも可）。
- **嫌い 2点**＋各一言の理由。
- 受け取ったら、要素ごとに言葉にして依頼者に返す（1行ずつ）: 線質／余白／文字の扱い（大きさ・書体）／要素の数／黒の量。**ズレていたらここで直す**。
- 参考の模倣にしない: 取り出すのは「要素の性質」だけ。構図・モチーフはコピーしない。

## 2. 3つの軸で現在地を決める（参考画像から推定 → 依頼者に1回確認）
| 軸 | 左端 | 右端 |
|---|---|---|
| 抽象度 | 具体物を描く | 図形・線・文字だけ |
| 密度 | 要素1〜2個・余白大 | 要素多数・にぎやか |
| 線か面か | 細い線のみ | 大きな黒の面 |

## 3. 固定条件
判型・余白・色数・載せてよい文言（これ以外の文字を作らない）・素材・書体条件・転用（B5→A6等）→ `spec-checklist.md`

## 4. 好みマップ（案件ごとに追記して残す）
各ラウンドで選ばれた案・却下された案を、上の3軸＋「骨格（文字だけ/図が主役/題字を崩す）」で1行記録する。
例: `R1 選:C(題字を崩す, 抽象, 密度低, 面) 却:A(文字だけ) 理由:「静かすぎ」`
→ 次のラウンドは**選ばれた位置の近く**で振る。同じ軸で逆戻りしたら記録を見直す。
