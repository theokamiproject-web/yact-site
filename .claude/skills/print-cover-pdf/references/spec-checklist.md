# 入稿仕様チェックリスト（依頼文から転記して使う）
| 項目 | 確認 | 備考 |
|---|---|---|
| 判型 | 幅×高さ mm | Chromium出力は上端基準で正確に切り直す（gray_pdf.py） |
| 塗り足し | あり/なし | なし → 仕上がり=入稿。端に接する図は作らない |
| 安全余白 | 文字・ロゴ・図は端から ≥ ○mm | 仕様値より大きく（実作業は仕様+4mm程度） |
| 色 | K単色 | 色演算子はグレー(g/G)のみ。ロゴの色味付き黒に注意 |
| ベタ | 大きな黒面不可 | オンデマンドのトナー剥がれ対策。線・文字・淡い網点は可 |
| 文字 | 曲線化 | フォント埋め込み0。縦組み/横組み、書体=明朝/ゴシック、商用可 |
| 写真 | なし | |
| 転用 | 縮小(A6等) | 縦横比が同じか。最小線幅が約半分になる点を説明に書く |
| 文言 | 依頼にある字句のみ | クレジット・価格・日付・キャッチを作らない |
| 納品物 | PDF＋プレビューPNG＋説明md | 説明: 意図2〜3行・書体/ライセンス・未確認事項 |
書体: Noto Serif JP（= Noto Serif CJK JP 同デザイン、SIL OFL 1.1、商用可）は `@fontsource/noto-serif-jp` で入手（文字ごとに分割ファイル。lib.mjs が探索）。
