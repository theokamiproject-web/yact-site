# 入稿仕様チェックリスト（依頼文と印刷会社の最新仕様から転記して使う）
> 下の「備考」の数値は例。**印刷会社の最新仕様が優先**。会社値を check_pdf.py の引数に渡す。
| 項目 | 確認 | 備考 |
|---|---|---|
| 判型 | 幅×高さ mm（塗り足し込みのページ寸法も） | Chromium出力は寸法が丸められるため gray_pdf.py が上端基準で切り直す |
| 塗り足し | あり/なし(mm) | なし → 端に接する図は作らない。あり → SVGは仕上がり+両側 |
| 安全余白 | 文字・ロゴ・図はトリム端から ≥ ○mm | 仕様値に数mm上乗せして設計する |
| 色 | K単色 | RGB/CMYK演算子ゼロ。ロゴの色味付き黒に注意 |
| ベタ | 大きな黒面の可否 | 会社仕様に従う。線・文字・淡い網点で代替 |
| 文字 | 曲線化 | フォント0・テキスト層0。縦/横組み、書体、商用可 |
| 写真 | なし/あり | ありなら本Skill対象外 |
| 転用 | 縮小(A6等) | 縦横比が同じか。最小線幅が縮小率だけ細くなる点を説明に書く |
| 文言 | 依頼にある字句のみ | クレジット・価格・日付・キャッチを作らない |
| 納品物 | PDF＋プレビューPNG＋説明md | 説明: 意図2〜3行・書体/ライセンス・未確認事項 |
書体の例: Noto Serif JP（SIL OFL 1.1、商用可）は npm `@fontsource/noto-serif-jp`（文字ごとの分割ファイル。lib.mjs が探索）。ライセンスは使用時に再確認。
