# 描く前に「視覚の方針」を1枚書く（canvas-design の2段階方式を、この用途向けに言い直したもの）
出典: anthropics/skills の canvas-design（Apache-2.0, https://github.com/anthropics/skills/tree/main/skills/canvas-design）。文章は写さず、方式だけ借りている。

## いつ
ブリーフ（`brief-template.md`）の後・描く前。骨格3案（`skeletons.mjs`）を出す前に1回だけ。

## 書くこと（全体で10行以内。説明mdとは別。依頼者に見せる必要はないが、案が選ばれたら説明mdの種にする）
1. **運動名**（1〜2語）: 例「余白の緊張」「巨大な一字」。作品の主題ではなく、見た目の態度の名前。
2. **方針**（3〜5行）: 空間・スケール・リズム・構図・視覚の優先順位を、それぞれ**1回ずつ**。文字は「視覚の要素」として扱い、説明に頼らない。
3. **捨てるもの**（1行）: 今回あえてやらないこと（例: 具体物・装飾・中くらいの大きさ）。
4. 3案は、この方針を**骨格を変えて**表現したもの、という関係にする。方針が同じで骨格が違えば、依頼者の反応から好みが読める。

## 気をつけること
- 丁寧に作り込んだ見た目（余白・揃え・線の太さの決め方）を、方針の中で毎回意識する。作り込みは手順ではなく態度。
- 既存の作家・作品の模倣をしない。参考画像から取るのは要素の性質だけ（`brief-template.md`）。
- 方針が長くなる＝決め切れていない。10行に収まらなければ削る。
