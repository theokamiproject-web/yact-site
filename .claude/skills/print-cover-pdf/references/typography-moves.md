# 題字を造形の対象にする（表紙の印象を最も大きく変える要素）
前例: 18案すべてで題字が「明朝の太字・縦組み・右端・同じ大きさ」のまま → 図形をいくら変えても定型に見えた。

## 毎回やること
- **書体を3種以上**試す（`lib.mjs` の `o.family`。@fontsource、すべて OFL）:
  明朝 `shippori-mincho-b1` `zen-old-mincho` `noto-serif-jp`／ゴシック `noto-sans-jp` `dela-gothic-one`(極太・400のみ)／
  手書き・筆 `yuji-syuku` `klee-one` `zen-kurenaido`。書体に無い文字は lib が例外 → 別書体に。
- **大きさは両極**: 紙面の高さ6〜8割を占める巨大か、本文並みの極小か。「中くらい」を避ける。
- 字間 `o.track`（em比。-0.1〜+0.5）で詰める／空ける。
## 崩し方（読み順は保つ）
1字ずつ大きさを変える／2列に割って段差をつける／字の一部を図形と重ねる・線で切る／余白ぎりぎりまで寄せる（安全余白は守る）／欧文や数字を混ぜる。
## 確認
`review_sheet.py` の縮小（幅30mm）で題字が読めること。読めない崩しは不可。
