# 権利・著作権の別紙を作るとき

## 文面の扱い

- ユーザーが法務文面を渡してきたら、語句は変えない。こちらがやるのは見出し・番号リスト化・太字の導入句だけ。
- 例外は「本体と矛盾する箇所」。直す前に、どこが本体とずれているかを報告し、直した後に何を変えたかを明示する。

## 本体との突合で毎回見る点

| 項目 | よくあるずれ | 対処 |
|---|---|---|
| 金額 | 本体は金額なしなのに、別紙が「制作費○万円」を前提にしている | 初回提案では総額を出さない。「想定している制作費の枠」に抽象化。弁護士費用のような別紙内で完結する実費見積もりは残してよいが、ユーザーに確認を一言 |
| 章参照 | 「第4章に記載した外販」等、本体の該当章にその話題がない（章番号は別の版のまま） | 本体に記述を足すか、参照を削るかをユーザーに選んでもらう。黙って本体に話題を追加しない |
| 章番号 | 本体が1〜6章なら別紙は7章から始まる、のように通し番号にするか | 通し番号なら本体の最終章番号を確認 |
| 体制・帰属 | 本体のクレジット（作・演出・出演・主催）と別紙の権利者・主催者の記述 | 同一人物・団体名の表記揺れも含めて一致させる |
| 差異化の論点 | 別紙の「原作との差異○点」と、本体あらすじ・設計表が実際にそうなっているか | あらすじを書き換えたら差異の各点が崩れていないか再確認 |

## 送付形態

- 別紙をPDFで同封するなら、本体の「参考資料」欄（Googleドキュメント等のリンク）は削除する。リンクは先方が開けないことが多い。
- 宣伝物には原作名を出さない方針のとき、本体の本文で原作名を出すのは「内部検討資料」扱いとして許容されるが、ユーザーに一度確認する。
