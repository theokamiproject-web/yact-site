# 物語の方向性を比較するときの型

ユーザーが結末・トーンの案を複数持ってきたら、決めるのはユーザー。こちらは比較材料と推奨を出して止まる。

## 1. 観客層×案のマトリクス（◎○△）

既定の観客層（ユーザーが別の層を挙げたらそれに差し替える）:

| 層 | 見る観点 |
|---|---|
| 地元在住者 | 自分たちの暮らしの本音を代弁しているか／地域の助け合い観と重なるか |
| 子ども | 筋と感情の変化が目で見てわかるか |
| 高齢夫婦 | 家・介護・継承の価値観にどう響くか（救いになるか、責められるか） |
| 都市部の演劇関係者 | 予定調和でないか／劇構造として核心に答えているか／演技として見せ場があるか |
| 提案先の俳優陣 | 自分たちの強み（歌・踊り等）が生きるか／役の心理的負荷 |

1行1案、各セルは「◎/○/△＋理由1行」。

## 2. 推奨の出し方

- 判定軸は「作品の骨格（人物表や設計表に書いた中心の対立）に直接答えているか」。情景の美しさだけで終わる案は、単独では推奨しない。
- 情景系の案は「最後の絵」として、骨格に答える案と組み合わせる（ハイブリッド推奨が多くなる）。
- 提案書の他の章（協働者を入れる理由、提案先の強み）と呼応する案を優先すると、営業資料としての一貫性が上がる。
- リスクを必ず添える: 要素を足しすぎて上演時間に収まらない／「みんなで助け合う」型の類型化（→職能を使った実務的な解決として描くと防げる）。

## 3. 明るくする書き換えの定石

- 重い設定（非正規・酷評・喪失）は人物表に残し、あらすじ本文からは削る。人物表が深みを、あらすじが希望を担う。
- 結末は抽象的な余韻より、具体的な絵で終える（例: 誰もいなくなった部屋に温もりだけが残る）。
- 決めた変更は、設計表・提案先への想いの章・結びまで波及するので、書き換えたら全章を突合する。
