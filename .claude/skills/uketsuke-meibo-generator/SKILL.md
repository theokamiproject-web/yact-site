# 受付名簿ジェネレーター

演劇・イベント公演の「ご予約フォーム（Googleフォーム）」の回答データから、当日の受付で使う**受付名簿PDF**を作成する。

## いつ使うか
「受付名簿を作って」「当日の名簿」「予約者リスト」「予約一覧」「◯◯公演の名簿」等の依頼。GoogleフォームやCSVの予約データがあることが前提。

## 手順

### 1. 予約データを取得する
- Googleフォームの回答は、通常「（フォーム名）（回答）」というスプレッドシートに入っている。Google Drive MCPの `list_recent_files` または `search_files` で「予約」「回答」などから探し、`read_file_content` で全行を取得する。
- CSVをユーザーが渡してきた場合はそれを使う。
- 列は概ね：タイムスタンプ／メールアドレス／お名前／ふりがな／公演選択／枚数／お飲み物／備考／応援キャスト（指名）。フォームにより増減するので**実データの列を必ず確認**する。

### 2. 対象公演で絞り、キャンセルを除外する
- 「公演選択」列で対象（例：東京公演のみ／金沢◯回のみ）に絞る。**同じ人が複数公演を予約している場合があるので会場・回で正しく分離**する。
- **キャンセルの検出（重要）**：
  - 備考欄に「キャンセル」を含む行 → その人の該当公演予約を無効化。
  - 別途メール（Gmail）で「キャンセル」連絡が来ていることもある。Gmailを `search_threads`（query例：`キャンセル OR 変更 newer_than:30d`）で確認し、該当者を除外。
  - 除外した人数・枚数は名簿の注記に「※キャンセル済（◯◯様）は除外」と明記する。
- 関係者・招待（差出人＝主催アドレスで登録、備考に「招待」等）も来場者なので**掲載する**。備考に「招待」「関係者」等を残すと受付で分かりやすい。

### 3. 並べ替えモードを決める
ユーザーに確認（デフォルトは予約順）。3モードとも同じ表形式で出せると便利：
- **予約順**（タイムスタンプ昇順）
- **五十音順**（ふりがな昇順）
- **指名別**（応援キャストごと。グループ順は主役→他、最後に「指名なし」。各グループの組数・枚数を把握したいとき）

### 4. レイアウトを選ぶ
- **A4縦・1段**：40名程度まで。本文が小さめ（約5pt）になるので詰め込み向き。
- **A4横・2段組（20名×2列）**：本文約9ptで読みやすい。**受付で使うならこちらが推奨**。
- 列：No／済（□チェック欄）／お名前／ふりがな／枚／備考。ヘッダに公演名・日時・会場・開場受付時刻・料金・予約合計（組/枚）を入れる。

### 5. PDFを生成する（下記スクリプトを使う）
日本語フォントは Source Han Serif（mplfonts同梱）を使い、必ず `language="ja"` を付けて描画する（付けないと中国語字形になる）。
- フォント準備：`pip install mplfonts --break-system-packages` 後、`.../site-packages/mplfonts/fonts/SourceHanSerifSC-Regular.otf` を使用。無ければ `fc-list | grep -i "Noto Serif CJK\|Source Han"` で代替を探す。
- 生成は PIL で描画 → `img2pdf` でA4に配置（`pip install img2pdf --break-system-packages`）。PILの直接PDF保存はJPEGエンコーダ不在で失敗しやすいので img2pdf を使う。
- ふりがなが長い行（例「たかはしゆうじとほのか」）は枚数欄に食い込むので、名前・ふりがなを短縮（例「高橋ゆうじ／たかはしゆうじ」）する。
- 生成後は必ずPDFを画像化して目視確認（`pdftoppm -f 1 -l 1 -jpeg -r 60 out.pdf chk` → 読む）。列ズレ・はみ出し・欠落（人数が合うか）をチェック。

### A4横2段組の生成スクリプト（テンプレート）
`rows` を `(お名前, ふりがな, 枚数, 指名, 備考)` のリストで用意し、並べ替え済みにしてから流し込む。

```python
# -*- coding: utf-8 -*-
from PIL import Image, ImageDraw, ImageFont
import img2pdf, glob, os
FONT = next((p for p in glob.glob("/**/SourceHanSerifSC-Regular.otf", recursive=True)
             or glob.glob("/**/NotoSerifCJK*.otf", recursive=True)), None)
DPI=300
def mm(x): return int(round(x/25.4*DPI))
W,H=mm(297),mm(210)  # A4 landscape
def F(s): return ImageFont.truetype(FONT,s)
def jt(d,xy,t,**k): d.text(xy,t,language="ja",**k)

TITLE="『作品名』◯◯公演 受付名簿"
SUB="2026年◯月◯日（◯）◯◯:00開演／会場名　開場・受付◯◯:◯◯／全席自由・当日精算3,000円"
rows=[  # ← 並べ替え済みで渡す
 ("お名前","ふりがな",1,"指名","備考(招待のみ等)"),
]
img=Image.new("RGB",(W,H),(255,255,255)); d=ImageDraw.Draw(img)
jt(d,(mm(12),mm(9)),TITLE,font=F(46),fill=(15,15,15))
total=sum(r[2] for r in rows)
jt(d,(mm(12),mm(21)),SUB,font=F(28),fill=(80,80,80))
jt(d,(mm(12),mm(28)),f"予約合計：{len(rows)}組 / {total}枚　※キャンセル済は除外",font=F(26),fill=(80,80,80))
sub=[("No",0,9),("済",9,8),("お名前",17,40),("ふりがな",57,32),("枚",89,8),("備考",97,35)]
COLW=mm(132)
def draw_col(ox,oy,chunk,start):
    d.rectangle([ox,oy-mm(1.5),ox+COLW,oy+mm(6.5)],outline=(120,120,120),width=1)
    for lab,x,wd in sub: jt(d,(ox+mm(x)+mm(1),oy),lab,font=F(24),fill=(15,15,15))
    yy=oy+mm(8.5); fb=F(38)
    for i,(name,furi,mai,cast,note) in enumerate(chunk):
        for (lab,x,wd),v in zip(sub,[start+i,"□",name,furi,mai,note]):
            jt(d,(ox+mm(x)+mm(1),yy),str(v),font=fb,fill=(15,15,15))
        d.line([ox,yy-mm(1.4),ox+COLW,yy-mm(1.4)],fill=(215,215,215),width=1); yy+=mm(8.1)
    d.line([ox,yy-mm(1.4),ox+COLW,yy-mm(1.4)],fill=(215,215,215),width=1)
    for _,x,_ in sub[1:]:
        d.line([ox+mm(x)-mm(1),oy+mm(6.5),ox+mm(x)-mm(1),yy-mm(1.4)],fill=(225,225,225),width=1)
half=(len(rows)+1)//2
draw_col(mm(12),mm(36),rows[:half],1)
draw_col(mm(152),mm(36),rows[half:],half+1)
img.save("受付名簿.png",dpi=(DPI,DPI))
a4l=(img2pdf.mm_to_pt(297),img2pdf.mm_to_pt(210))
open("受付名簿.pdf","wb").write(img2pdf.convert("受付名簿.png",layout_fun=img2pdf.get_layout_fun(a4l)))
```
A4縦1段にしたい場合は `W,H=mm(210),mm(297)`、1列で全行、行ピッチ mm(5.7〜6.2)、本文フォント F(20) 程度にする。

指名別モードは、指名（応援キャスト）で `order={"主役名":0,...,"":9}` を作りグループ順に連結してから `rows` に渡す（グループ見出しを入れる場合は各グループ先頭に赤字ヘッダ行を描く）。

### 6. 仕上げ
- ふりがな順・予約順・指名別の複数版を求められたら、`rows` の並べ替えだけ変えて再生成。
- 集金用に「金額（枚数×単価）」列を足した版も出せる。
- 生成物は `present_files` でPDFを渡す。ファイルがロックされて上書きできない時は別名（_v2 等）で出力する。

## 注意
- 予約者のメールアドレス・氏名は個人情報。名簿には氏名・ふりがな・枚数・指名・備考のみ載せ、メールアドレスは載せない。
- 人数の検算（組数・合計枚数）を必ず行い、フォームの集計と一致するか確認する。

## こりっちの「予約一覧表」PDFから来場リストを作る

予約管理がこりっち（または同様の予約システム）の場合、入力は回ごとの「予約一覧表」PDF（A4横、列：公演日時／予約No.／名前／名前（カナ）／チケット名(料金種別)／枚数／席番号／支払方法／取扱窓口／備考）。団体が過去公演で使った**来場リスト（Excel製、A4縦）**の形に合わせて出すのが定番。

### 手順
1. **見本を確認する**：「〇〇と同じ形式で」と言われたら、見本（過去の来場リストPDF）をDriveで探して `pdftotext -layout` と画像化で列・色・並び・合計の位置を確認する。ノアノオモチャバコの来場リストは：列「公演日時｜名前｜フリガナ｜取扱窓口｜支払方法｜料金種別｜単価｜枚数｜合計金額｜備考」、名前セル黄色、招待は赤字、キャンセルは名前セル赤＋枚数0＋備考「キャンセル」、最下段に枚数合計、当日券の書き込み行。
2. **料金を確定する**：PDFには単価が無い。料金種別ごとの単価を公演の告知（特設サイト等）で確認する（推測しない）。
3. **変換する**：`scripts/corich_raiba.py`
   ```
   python3 scripts/corich_raiba.py 予約一覧表.pdf --title "31日(土)12時" \
     --price 一般=3500 --price U25=3000 --price 招待=0 \
     --walkin 5 --walkin-price 4500 --outdir out --pdf-out
   ```
   - キャンセル：`--cancel 予約No.`（行ごと削除）。「行は残して赤」で求められたら、Excelで名前セル赤・枚数0・備考「キャンセル」にする。
   - 窓口の付け替え：`--no-mado 予約No.`（例：取扱窓口を外して招待の並びへ）。
   - 並び：取扱窓口ありを窓口ごと（PDFの出現順）→窓口なし→窓口なしの招待。
   - 1回分＝A4縦1枚に収まるよう fitToPage 済み。PDFは LibreOffice（soffice）で変換。
4. **検算と目視**：出力の件数・枚数・金額を、こりっちの集計（または前回の数）と照合する。PDFを画像化して、折り返した名前（「〇〇美術館 北島」など2行の名前）、複数種別の行（「前売り×2・U25割×2」）、長い備考の行を目視確認する。

### 判断ルール
- キャンセル連絡（メール・DMのスクショ）が来たら → 予約No.・名前・フリガナで照合して特定。件名や本文の作品名が違っていても（「映画『〜』」など）、名前とフリガナが一致すれば同一予約として扱い、その旨を報告する。
- 1件に複数の料金種別がある予約 → 単価欄は合計額、料金種別は「前売り×2・U25割×2」の形。
- 同一人物が複数回・複数件の予約 → 消さずに残し、報告で指摘する。
- 「A4一枚に」と言われたら → fitToHeight=1（スクリプト既定）。縮小率が大きく読みにくければ当日券行を減らす案を出す。

### 失敗しやすい点
- `pdftotext -layout` の文字列から列を切ると、2行に折り返した名前・備考で列がずれる → **必ず `-bbox` の座標で列を割り当てる**（スクリプトは見出し語のx座標から列境界を自動決定）。
- 2ページ目以降は見出しのy座標が1ページ目と違う → ページごとに「公演日時」見出しのyを取り、それより下だけを本文にする（固定値で切ると各ページ先頭の行が落ちる）。
- ページ番号「1/3」が料金種別の列に混入する → 数字/数字だけの語を除外。
- 料金種別の括弧が別の語・別の高さで出る（「前売」「(」「一般」「)」）→ 同じ行の語を連結してから括弧の中身を取り出す。
