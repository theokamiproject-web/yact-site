# 共催に足るかのチェック（内部用）

内部の検討用ドキュメントに「共催チェック」として置く。提出用の企画書には評価そのものは載せない。

## 10の観点と評価の付け方

評価は「強み／ふつう／弱み」の3段階（Claude Docs ならドロップダウンのenumにして、ユーザーが変えられるようにする）。各行に「根拠（数字）」と「弱いところ」を必ず書く。

| 観点 | 強みと言える目安 | 弱みになりやすい状態 |
|---|---|---|
| 県民への鑑賞機会 | 複数ステージ、手の届く料金、前回の予約率が高い | 1回だけ、料金が都市部と同じ |
| 国の指針・地域計画との合致 | 指針4(1)(2)と地域計画の柱に1対1で対応 | 鑑賞だけで、学校・若手・参加がない |
| 子ども・若者 | 学校との連携、若者が上演する機会、U18無料 | 割引料金だけ |
| 県民の参加（深さと規模） | 数か月関わる参加（出演・朗読）と、気軽な参加の2段 | 1回45〜60分の体験だけ、延べ数十名 |
| 地域らしさ | 作品・題材・出演者に地域との接点 | 東京公演をそのまま持ってくるだけ |
| 継続性 | 同じ会場で複数回の実績、複数年の計画 | 単発 |
| 集客の見込み | 前回の予約数・予約率の実績 | 回数を増やすのに根拠がない |
| 劇場の費用と作業の負担 | 劇団が制作・運営・安全管理を担う | 劇場に求めることが曖昧 |
| 安全と運営 | 受付1か所、危険な内容に制限・保険 | 一般参加者が舞台・セットで動く、殺陣など |
| 劇場にとっての広報価値 | 「高校生が上演」「市民が出演」など記事になる要素 | 劇場の事業一覧で目立つ要素がない |

結論は一文で先に書く：「今のままでは共催より貸館に近い／条件付きで共催に足る／共催に足る」。理由は弱みの観点名で言う。

## 会場側・市民側のメリットとデメリット

- 会場側メリットの型：人手をかけずに共催事業の件数・参加型事業の実績が増える／前回実績があり運営リスクが低い／関係人口の例として説明できる。
- 会場側デメリットの型：共催名義での責任（中止・事故）／会場費を下げれば劇場収入が減り、他団体から同じ要望が来たときに断る理由が要る／演目未定だと中身を保証できない／一般参加者が舞台に上がる安全管理。
- 市民側メリットの型：都市部より安く観られる／観劇者・U18無料のWS／経験不問で入れる講座（殺陣など）。
- 市民側デメリットの型：WSが1日だけなら他の日の観客は再訪が必要／終了時刻が遅いと市外の中高生が帰れない／障害のある人への配慮が書かれていない／演目未定で家族向けか判断できない。

## 修正案を出されたときの再チェック

ユーザーが案を修正したら（日程・講師・対象の変更など）、同じ観点で「上がる／要検討／要確認／必須」を付け、各行に具体的な提案を書く。とくに確認するのは：
- 同じ時間帯に舞台を取り合わないか（参加者の場当たり vs 出演者の本番準備）
- 参加者の家族が観に来るときのチケットと座席
- 地域の学校行事（大会・文化祭）と会期の重なり（高校の文化連盟に日程を聞く）
- 稽古の体制（誰がどこで、何時まで）と必要書類
- 収支に入っていない費用（執筆、稽古場、謝礼、保険）
- 出演者の1日の拘束時間
