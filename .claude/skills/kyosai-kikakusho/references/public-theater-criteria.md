# 公共劇場が共催を判断するときの評価軸

共催の可否は「劇場が自分の上司・設置者（県・市）・指定管理の評価に説明できるか」で決まる。企画書は、劇場が引用できる根拠の言葉に、企画の中身を対応させる。

## 1. 国の指針（全国共通・必ず使う）

[劇場，音楽堂等の事業の活性化のための取組に関する指針](https://www.bunka.go.jp/seisaku/bunka_gyosei/shokan_horei/geijutsu_bunka/gekijo_ongakudo/pdf/shishin.pdf)（平成25年文部科学省告示第60号）。企画書で引けるのは主に次の3項目。

| 指針の項目 | 要旨（企画書に書く言い方） | 対応させやすい取り組み |
|---|---|---|
| 4(1)ア 普及啓発 | 鑑賞機会の提供にとどまらず、利用者が参加する取り組み | ワークショップ、市民の出演・朗読、公開稽古、バックステージツアー |
| 4(1)イ | 年齢や障害の有無にかかわらず社会参加の機会を拡充 | 観劇サポート回（リラックスパフォーマンス）、車いす席・事前の舞台説明 |
| 4(2) 児童生徒 | 子どもが質の高い実演芸術に触れる機会。学校を訪問しての公演等 | 高校生・中学生の上演機会、学校への出張WS、U18無料、学校への案内 |
| 4(2)ウ・5 連携 | 他の劇場・実演芸術団体との共同制作、巡回公演 | 東京公演から続くツアー、複数年の継続 |

## 2. 都道府県・市の文化振興計画（案件ごとに調べる）

- 検索：「{都道府県} 文化振興ビジョン 施策」「{都道府県} 文化芸術推進基本計画」「{都道府県} 文化芸術推進協議会 資料」。
- 取るもの：計画期間、基本方針（施策の柱）、成果指標（鑑賞率・活動率・来場者数など）。成果指標は「この企画で劇場が報告できる数字」に直結するので必ず拾う。
- 秋田県の例：第4期あきた文化振興ビジョン（2026〜2029年度）＝「県民が文化芸術に親しむ機会の充実」「文化芸術による秋田の魅力の創造（交流人口・関係人口）」「文化の継承と次代を担う人材の育成（学校での体験、若手の発表の場）」。

## 3. 劇場・指定管理者の課題（あれば強い）

- 検索：「{劇場名} 指定管理 実施要領」「{劇場名} サウンディング」「{劇場名} 管理運営 基本方針」。
- 例：あきた芸術劇場の実施要領（秋田県、2024年7月）は「県市主催事業の更なる充実」「集客力のある公演の誘致」「周辺施設と連携したにぎわい創出」を課題に挙げていた。共催事業はこの実績に数えられる。

## 4. 劇場自身の前例

- 劇場サイトのお知らせ・イベント一覧で「ワークショップ」「関連企画」「共催」を検索。公演と関連ワークショップを組んだ前例があれば、「劇場になじみのある形」として引用する（例：公演前日に出演者が県内の子どもを指導した回）。

## 5. 会場の予約ルール（最初に確認する）

- 利用案内PDFを `curl -sSL -o guide.pdf {URL}` → `pdftotext -layout guide.pdf -` で読み、`か月前` `先行予約` `抽選` `受付期間` `休館日` `減免` `18歳未満` `連続` を grep。
- 公共ホールは「利用希望日のNか月前の月の初日から数日間」だけ受け付け、重なれば抽選、という方式が多い。本番月から受付日を計算し、曜日（休館日と重ならないか）を python で確認して、今日からの日数と一緒に最初に報告する。
- 高校生・18歳未満がホールで発表する場合の書類（学校の許可書・保護者の同意書）、20時以降の責任者同伴などの条件も同じPDFに書かれていることが多い。
