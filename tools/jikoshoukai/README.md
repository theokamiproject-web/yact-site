# 夢授業 自己紹介スライド ― 写真の流し込み

9/28 第一高等学院秋田校「演劇の世界に触れてみよう」で使う自己紹介スライド
（`夢授業_自己紹介_v4.pptx`）の、Q1〜Q4 にある8つの写真枠を埋めるためのスクリプト。

## 使い方

```
pip install pillow
mkdir photos                      # ここに写真を置く（このリポジトリには入れない）
python3 insert-photos.py 夢授業_自己紹介_v4.pptx 夢授業_自己紹介_v5.pptx
```

写真の割り当ては `insert-photos.py` 冒頭の `MAPPING` で決める。

| | 左（真坂） | 右（寺戸） |
|---|---|---|
| Q1 今、何をしている人ですか | 舞台に立っているところ | 稽古場 |
| Q2 子どもの頃 | 赤ちゃんの頃の写真 | 赤ちゃんの頃の写真 |
| Q3 演劇に入ったきっかけ | 公演後の集合写真 | 学生時代の劇団の集合写真 |
| Q4 ふだんの仕事 | 稽古・ワークショップ | 劇場（ポケットスクエア） |

## 仕組み

- 写真は枠と同じ 1600x837 px（4.3in x 2.25in、枠 3931920x2057400 EMU と同比率）に
  整えてから埋め込む。枠と比率が同じなので、写真がつぶれず左右の揃いも崩れない。
- `cover` … はみ出す分を切る。`focus`（0〜1）で上下どこを残すか決める。顔が上にある
  写真は 0.4 前後、集合写真は 0.6 前後。
- `contain` … 縦長の写真や極端に横長の写真は、全体を残して余白を枠と同じ色で埋める。
  余白の色は左 `#ECE2D0`、右 `#E4EDF0`（枠の塗りと同じ）。
- 余白を出さず枠線までびっしり入れたいときは、`MAPPING` の5番目に切り取る範囲を
  割合（左, 上, 右, 下）で書いてから `cover` にする。真坂Q2がこの形。
- 写真が入った枠は破線の枠線を実線にし、「写真：〇〇」の文字を消す。写真を入れなかった
  枠は破線と文言がそのまま残る。
- スライド本体の文言・ノートは触らない。文言を直すときは元の `build-pptx.js` の
  `QS` 配列を直してから、このスクリプトを掛け直す。

## 見出しの字数

見出し枠の内寸は 295pt（3931920 EMU から左右の余白 91425 EMU ずつを引いた幅）。
本文が 22pt なので、全角で **13字** を超えると2行に折り返す。
`ひとりでトーマスを走らせてた`（14字＝308pt）が現状ただ一つの超過。

## 注意

写真そのものと出来上がった .pptx は、このリポジトリが公開されているため入れていない。
写真は Google Drive の共有フォルダに置いたまま扱う。
