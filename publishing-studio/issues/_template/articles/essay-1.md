ここにエッセイ本文を書きます。ページに収まる量は、レイアウトごとに目安があります。この「essay / opener」は仕上がり A5 で約700字です。それを超えると台割の検証で警告が出て、実際にあふれた場合は preflight が FAIL になります。

原稿が長いときは、台割で同じ記事を複数ページに割り当てます（例: opener のあとに body や end）。文章は記事の先頭から順に、各ページの容量に応じて自動で配分されます。段落の途中は句点で区切られます。

写真を入れたいときは images/ に画像を置き、記事の assets に書き、captions/captions.yaml にキャプションを書きます。詳しくは README を参照してください。
